  HƯỚNG DẪN – VÌ SAO MÁY KHÁC KHÔNG THẤY THAY ĐỔI?
═══════════════════════════════════════════════════════════

KHÔNG CÓ BACKEND = MỖI MÁY KHÔNG TỰ ĐỒNG BỘ
────────────────────────────────────────────
  • Bấm "Lưu" trong admin → lưu thêm vào TRÌNH DUYỆT máy đó.
  • Máy khác / điện thoại khác / trình duyệt khác → KHÔNG thấy,
    trừ khi bạn làm thêm bước bên dưới.

  → Đây là lý do bạn sửa xong mở máy khác vẫn thấy bản cũ.

CÁCH ĐÚNG ĐỂ MỌI NGƯỜI XEM GIỐNG NHAU (CÓ HOSTING)
────────────────────────────────────────────
  1. Vào admin.html → sửa nội dung
  2. Bấm "Lưu & tải content.json"
     → Máy tải file tên: content.json
  3. Upload file content.json lên hosting,
     CÙNG THƯ MỤC với index.html (ghi đè file cũ)
  4. Khách mở https://tenmien.com/index.html → thấy bản mới

  Mỗi lần sửa lại: Lưu → upload content.json mới.

CHƯA CÓ HOSTING / CHỈ DÙNG FILE TRÊN MÁY
────────────────────────────────────────────
  • Máy A: Lưu → tải content.json
  • Máy B: admin.html → "Nhập JSON" → chọn content.json
  • Hoặc copy content.json vào cùng folder với index.html
    (chỉ xem được qua hosting hoặc chạy local server,
     không xem được nếu double-click file khi file://)

MỞ FILE BẰNG DOUBLE-CLICK (file://)
────────────────────────────────────────────
  Trình duyệt KHÔNG đọc được content.json (bảo mật).
  Chỉ thấy thay đổi trên ĐÚNG máy + ĐÚNG trình duyệt đã Lưu.
  → Muốn test đúng: đưa lên hosting hoặc dùng Live Server.

ĐĂNG NHẬP ADMIN
────────────────────────────────────────────
  Mật khẩu mặc định: vietkite2026
  Đổi trong admin.html → CONFIG.password

FILE TRONG BỘ
────────────────────────────────────────────
  index.html, admin.html, cms.js, cms-default.js
  content.json  ← tạo sau lần Lưu đầu; upload lên web
